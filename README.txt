전기 계산기 사용 방법

1. 이 폴더를 원하는 위치에 복사하거나 압축을 풉니다.
2. index.html 파일을 더블클릭합니다.
3. 기본 브라우저(Chrome, Edge 등)에서 열리면 사용할 계산 탭을 선택합니다.
4. 입력값을 적고 파란색 계산 버튼을 누릅니다.

별도 설치나 인터넷 연결은 필요하지 않습니다. HTML, CSS, JavaScript 파일이 같은 폴더에 있어야 합니다.

계산 기준
- 단상 유효전력: P(kW) = V × I × 역률 ÷ 1,000
- 삼상 유효전력: P(kW) = √3 × V × I × 역률 ÷ 1,000
- 전압/전류: 위 식을 변형해 모르는 값을 구합니다.
- 삼상 모터 예상전류: I(A) = P(kW) × 1,000 ÷ (√3 × V × 역률 × 효율)
- EOCR은 단상/삼상을 선택할 수 있습니다. 효율 기본값은 100%이며, 효율 칸을 비워도 100%로 계산합니다. 직접 입력은 최대 125%까지 가능합니다.

EOCR 계산값은 참고값입니다. 실제 설정에는 모터 명판 전류와 제품 설명서를 확인하세요.

추가 기능
- 입력값 지우기: 각 계산 탭 아래의 '입력값 지우기'를 누르면 해당 탭의 입력과 결과를 초기화합니다.
- 마력/kW 변환: HP ↔ kW 탭에서 방향을 선택해 변환합니다. 기준은 1 HP = 0.7457 kW입니다.

CT비 계산
- CT 1차·2차 정격은 CT 명판대로 입력합니다. 예: 100/5 A. 두 칸을 모두 비우면 CT 환산 없이 모터 전류를 표시합니다.
- EOCR 결과는 모터측 예상전류 × (CT 2차 정격 ÷ CT 1차 정격)입니다. 예를 들어 100/5 CT는 모터 전류를 1/20로 환산합니다.

iPhone에서 웹으로 사용하기
- 이 앱은 별도 서버 코드 없이 정적 웹 호스팅에 게시할 수 있도록 구성되어 있습니다.
- index.html, style.css, app.js를 같은 폴더에 둔 채 HTTPS 주소로 게시하면 iPhone Safari에서 주소를 열어 사용할 수 있습니다.
- 아직 공개 웹 주소는 연결되지 않았습니다. 게시하려면 GitHub Pages, Netlify, 또는 보유 중인 웹 호스팅 중 하나가 필요합니다.
